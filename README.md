# 全能本地播放器

一个 Windows 上的本地音视频播放器：经典 WinForms 界面，播放内核用 VLC（libvlc 3.0.24），
**不需要另装 VLC**。

## 功能速览

- **播放**：文件 / 文件夹（递归）/ 网络串流 / DVD / 音频 CD；MP4、MKV、AVI、MOV、FLV、WebM、TS、RMVB…，
  MP3、FLAC、APE、WAV、AAC、M4A、OGG、Opus、WMA…；倍速、循环、随机（一轮不重复）、A-B 循环、
  睡眠定时器、音量均衡、画面比例、全屏、截图。
- **播放列表**：搜索过滤（空格分隔多关键字）、按名称 / 路径 / 时长排序、点表头排序、拖动换位、「下一首播放」队列、
  找重复项；**多选批量移除 / 下一首 / 复制路径 / 整批上移下移与拖动**（`Ctrl` / `Shift` / `Ctrl+A`，
  `Ctrl+Z` 撤销最近一次移除或清空）；汇总总时长；
  m3u / m3u8 导入导出；歌单库（标准 m3u8；窗口内多选按块拖动排序）；网络目录整目录拖入，扫描可见、可取消。
- **歌词与封面**：同目录 `.lrc` → 内嵌歌词 → `.txt`；UTF-8 / UTF-16 / GBK；点行跳转、悬停看时间、
  按文件记住的歌词偏移；内嵌 / 外挂封面；可选 LrcAPI 在线歌词与封面（地址自己填，密钥 DPAPI 加密，
  128 MB 本地缓存）。
- **侧栏**：歌词 / 封面 / 媒体信息 / 视频 / 文件五页；音画与字幕延迟、画面旋转、去隔行、逐帧、
  章节、音频输出设备；多数调整按文件记住。
- **文件浏览器（1.24 ～ 1.28）**：侧栏第 5 页，也能分离成独立窗口。地址栏 + 返回 / 前进 / 上级 / 刷新；
  只读当前一层，默认只看音视频 / 字幕 / m3u；按名称 / 大小 / 时间 / 类型排序；收藏目录与最近浏览；
  搜索当前文件夹（空格分隔多关键字，`Ctrl+F`）；勾选「含子文件夹」后按 `Enter` 递归搜索，
  结果带「位置」列；只看类型（视频 / 音频 / 字幕 / 播放列表）；可选「缩略图（平铺）」用封面
  或**视频首帧**平铺显示（后台解码、有界、落盘缓存；网络位置只显示图标；开关也在主菜单「视图」里）；
  **文件夹树**（左侧栏，懒展开、跟列表同步）与**自动刷新**（盯住当前本地目录，静默跟随增删改）；
  双击播放，右键加入列表 / 下一首 / 递归加整个文件夹；也能拖到播放列表、定位当前播放文件。
- **桌面歌词**：透明、置顶、不抢焦点；`Ctrl+Alt+D` 全局锁定（鼠标穿透）；外观对话框边拖边改；
  字体只列自己导入的那些。
- **窗口与主题**：5 套主题；三栏布局；音频 / 视频两种窗口形态；迷你模式；侧栏、播放列表、
  文件页都能脱离主窗口并吸附；**音频窗口里也能把侧栏分离成悬浮窗**（停靠的侧栏照旧收起）；全屏进度条。
- **系统集成**：托盘、全局媒体键、系统媒体控件（SMTC）、任务栏缩略图按钮、单实例、按文件续播；
  快捷键可改（`帮助 → 快捷键设置…`，命令目录里那 33 条，改完立刻生效）；
  便携模式（程序旁放 `portable.ini`，数据全在程序目录里）。

完整说明见 [参考手册](docs/参考手册.md)。

## 下载与安装

从 [Releases](https://github.com/non266/local-player/releases) 下载：

| 形态 | 适合 | 说明 |
| --- | --- | --- |
| `local-player-<版本>-setup.exe` | 日常使用 | 每用户装到 `%LocalAppData%\Programs\全能本地播放器`，不弹 UAC；开始菜单有程序与卸载；桌面图标可选；自包含，装完即用 |
| `local-player-<版本>-portable.zip` | 免安装 / U 盘 | 解压即用，`播放器.exe` 在根目录，不写注册表 |

- 安装包**没有数字签名**，首次运行会出现 SmartScreen「未知发布者」，不是包坏了。
- 安装器只把本程序加进 **52 种**音视频 / 播放列表格式的「打开方式」候选，不抢默认程序，
  也不注册字幕格式。
- **卸载不删用户数据**：设置 / 历史 / 歌单 / 字体 / 在线缓存都在 `%AppData%\播放器`；
  卸载器只撤掉程序与崩溃转储配置。
- 本机 1.32.0 实测：安装后约 **649 个文件 / 245.5 MB**（覆盖安装 245.9 MB）；便携包解压约 **647 个文件 / 241.1 MB**。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11（x64） |
| SDK | .NET 10 SDK（`global.json` 钉在 **10.0.402**；更高版本也能构建） |
| 运行时 | .NET 10 Desktop Runtime——只有"自己构建后直接运行"才需要；发行包自包含 |

播放内核以 NuGet 包引入，不需要预装 VLC。

## 构建与运行

```powershell
dotnet restore 播放器.csproj
dotnet build 播放器.csproj -c Release
.\bin\Release\net10.0-windows10.0.19041.0\播放器.exe
```

也可以直接用 Visual Studio 打开 `播放器.csproj` 按 F5。工程固定 x64，只复制一套 libvlc 原生库。

## 测试

冒烟测试覆盖内核、窗体、设置、标签 / 歌词、列表、光盘、网络位置、文件浏览器、文件页导航等，共
**35 个运行步骤 / 40 项检查**；不需要外部媒体文件，需要真实视频的那一步用 `播放器_TEST_VIDEO`
指定，不指定就如实跳过。

```powershell
dotnet build 播放器.csproj -c Debug
dotnet build tools/SmokeTest/SmokeTest.csproj -c Debug
cd bin/Debug/net10.0-windows10.0.19041.0
$env:播放器_TEST_VIDEO = "D:\某个视频.mp4"   # 可选
dotnet SmokeTest.dll                          # 全量约 5～6 分钟
dotnet SmokeTest.dll 文件浏览器                # 只跑某一块
```

文档与源码的一致性、发版前的完整检查：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\docs-check.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools\release-check.ps1
```

> 跑全量冒烟时不要有全屏游戏占着前台；音频窗口关闭那一处从 1.18.0 起偶发
> Application Hang（`0xCFFFFFFF`）——1.29.0 起引擎释放挪到后台、界面最多等 2 秒，
> **不会再挂住窗口**，但根因未定；遇到退出码非零的旧日志仍按"重跑"处理。

## 数据与配置

默认在 `%AppData%\播放器\`：`settings.json`（设置）、`history.json`（续播与按文件调整）、
`播放列表\`（歌单库，标准 m3u8）、`设置方案\`、`fonts\`、`online-cache\`、`缩略图缓存\`（`thumbnails\`）、`播放器.log`。

想把数据随身带，两种办法（1.29.0）：

1. **便携模式（推荐）**：在 `播放器.exe` 旁边放一个空文件 `portable.ini`，数据就落到
   `<程序目录>\data`（设置 / 历史 / 歌单 / 字体 / 缓存全跟着走）。程序目录写不进去会退回
   `%AppData%` 并在状态栏说明。**发行包里不预置这个文件**——解压覆盖旧目录时数据不会搬家。
2. **环境变量**：`$env:播放器_DATA_DIR = "$PSScriptRoot\data"` 再启动（优先级高于 `portable.ini`）。

设置与历史都是"先写临时文件再改名"的原子写；坏掉的 `settings.json` 会备份成 `.corrupt`
并尽量逐项救回。细节见 [参考手册的「设置文件」](docs/参考手册.md#设置文件)。

## 已知限制

- **只有 Windows（x64）**，没有跨平台计划。
- **没有画面调整**（亮度 / 对比度 / 饱和度 / 色相 / 伽马）：libvlc 3.0.24 上实测 `adjust` 滤镜会把
  画面变成纯绿，所以不做。
- **字幕外观只影响纯文本字幕**，参数是内核级的，保存后下次启动生效；ASS / SSA 与 DVD 图形字幕
  不受影响。
- **DVD 菜单只验过键盘**，鼠标点菜单没有真盘验证；蓝光只识别不播放；CSS 加密 DVD 不带
  `libdvdcss`。
- **在线歌词 / 封面要自己填 LrcAPI 地址**，默认不联网；封面图常挂在外部主机上，能不能显示
  取决于网络。
- **文件浏览器只做"找与放"**：不删 / 不改名 / 不移动；搜索默认只筛**当前文件夹**，
  勾选「含子文件夹」后按 `Enter` 才有界递归（本地 32 层 / 20,000 条结果 / 200,000 个已看条目，
  网络 16 层 / 10,000 条 / 100,000 条；不建索引，也不跟目录联接）；
  **文件夹树默认关**，只在视图宽度 ≥ 360 逻辑像素时可用，树里每层最多 2,000 个文件夹、不展开目录联接；
  **自动刷新默认开**，但只盯当前**本地**一层（网络位置与"此电脑"不盯，搜索结果页也不刷新）；
  「缩略图（平铺）」默认关：封面优先，没有封面才截**视频首帧**（片头全黑就退回类型图标），
  **网络路径不做**、每目录最多 300 个文件 / 其中 60 个视频截帧；**只按当前可见范围排队**（前后各一屏，
  滚动时补），内存缓存 512 条、满了只重建当前可见范围；缩略图**落盘**在
  `%AppData%\播放器\thumbnails`（上限 128 MB，不打开则不产生）；
  平铺里没有大小 / 位置列（搜索结果会自动回详情视图）；
  单目录上限 20,000 项；隐藏 / 系统项默认不显示；
  网络共享只能从地址栏进；拖放文件夹与整文件夹导入是有界的
  （32 层 / 200,000 文件，不跟目录联接）。
- **播放列表多选（1.31.0 / 1.32.0 / 1.33.0）** 用于批量移除 / 下一首 / 复制路径 / 整批上移下移与拖动；
  多选按**一个块**移动，块内相对顺序不变（非连续选中会跨过中间未选中的项）。
  筛选状态下不能整批移动 / 拖动（单选移动仍可用）。`Ctrl+Z` 撤销**最近一次移除或清空**：
  清空仍先走确认框，确认后也能用右键「撤销清空」恢复；条目不恢复播放、不恢复选中、不跨重启；
  列表内容再变一次（添加 / 排序 / 载入 / 移动 / 清空）就失效。
  「在资源管理器中显示」一次只能定位第一项；`Ctrl+A` 只选当前可见行。
- **歌单窗口多选整批拖动（1.33.0）**：选中几份歌单后按一个块拖动排序，块内相对顺序不变；
  只改 `歌单顺序.txt`，不碰歌单内容。拖错了只能再拖回去，或删掉那个文件回到按名字排（没有撤销栈）。
- **音频窗口里没有停靠的侧栏 / 播放列表**（1.9.0 的设计不变），但可以**把侧栏分离成悬浮窗**：
  分离后文件页也能用；迷你模式里不能再新分离，已经分离的可以归位。
- **媒体信息里的轨道码率 / Profile / Level 多半读不到**（libvlc 3 对 mp4 报 -1 / 0），读不到就不写。
- **播放记忆按文件路径**，改名或移动后重新开始记。
- **系统媒体控件（SMTC）** 需要 Windows 10 2004 以上；系统界面上到底画没画出来，冒烟验不到，
  只能人眼看。
- 已知偶发 **Application Hang**（`0xCFFFFFFF`，音频窗口关闭时）——1.29.0 起关窗**有界**
  （引擎释放挪到后台、界面最多等 2 秒，超时记一行后照常关窗），不会再把窗口挂住；
  **根因未定**，若频繁出现请附日志与转储。
- **快捷键覆盖命令目录里那 33 条**：主 / 次各一个键；`F1` / `Delete` / `Esc` / `Enter` / `Tab` /
  `Backspace` / `F5` / `Ctrl+F` / `Alt+←→`、文件页与 DVD 菜单那些键、全局热键与多媒体键不能改
  （绑上去会被那一处先吃掉，对话框会挡住）。
- **便携模式不预置**：便携 zip 里没有 `portable.ini`，要自己放；程序目录写不进去会退回
  `%AppData%\播放器` 并说明（不会静默换地方）。

更完整的边界与实测数据见 [docs/介绍.md](docs/介绍.md) 与 [docs/参考手册.md](docs/参考手册.md)。

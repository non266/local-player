## 1. 真机实测（不是猜的）

### 1.1 DVD 打不开：随包的 libvlc 少两个访问插件

- `libvlc\win-x64\plugins\access` 里有 `libcdda` / `liblibbluray` / `libvcd`，**没有**
  `libdvdread_plugin.dll`、`libdvdnav_plugin.dll`——`VideoLAN.LibVLC.Windows` 3.0.24 这个包就少了它们。
- 用 P/Invoke 直接问 libvlc：`dvd:///L:` 与 `L:\VIDEO_TS` 都是 `state=6（Error）`，
  控制台原话 `VLC is unable to open the MRL`。
- 把 **VLC 3.0.24 官方 win64 包**（同版本）里的这两个插件放进同一套 libvlc：
  `dvdsimple:///L:` 返回 `state=3（Playing）`、`length=1,429,434 ms`。
- 本机 `L:` 是 Optiarc DVD RW，盘里 `VIDEO_TS` 五个 VOB，共约 4.5 GB；没有 CSS 解密报错。
- 修法：`native\vlc-3.0.24\` 收下这两个文件（`native\README.md` 记了来源与 SHA256），
  `播放器.csproj` 用 `Content + Link + CopyToPublishDirectory` 复制进输出目录的
  `libvlc\win-x64\plugins\access\`（和 VLC 包自己那 300 多个插件的机制一样）。

### 1.2 任务栏按钮：注册发生在窗口显示之前

- 代码从 1.0 基线起就在：`OnHandleCreated → InitializeSystemIntegration → UpdateTaskbarIcons
  → SetIcons → Update → EnsureAdded → ThumbBarAddButtons`。那一刻窗口**还没显示**，任务栏上还没有它的按钮。
- 本机悬停任务的预览面板截图：只有标题 + 缩略图，**没有按钮条**；对照实验（窗口可见之后再加）能显示。
- Explorer 对"窗口还没显示就加按钮"照样返回 `S_OK`，于是 `_added` 一置真，**之后再也不重试**。
- 修法：`EnsureAdded` 的第一道守卫要求 `IsWindowVisible(窗口)`；注册改由 `OnShown` / `OnVisibleChanged` 触发；
  句柄重建走 `Attach`；每次尝试都把 `HRESULT` / 可见性 / 按钮数写进日志。修完真机日志：
  `任务栏缩略图按钮：挂载 hr=0x00000000（0 为成功），按钮 4 个，窗口可见=True，这是第 1 次尝试`。

### 1.3 全屏里为什么不能"塞一个控件"

`EnterFullscreen` 把菜单 / 工具栏 / 状态栏 / 传输条全收起来、两栏折叠、窗口铺满屏幕；
而画面是 **libvlc 自己的子窗口**，WinForms 控件盖不上去（1.8.0 做画面右键菜单时实测过，
所以那个功能是 30 ms 轮询键状态实现的）。把 `pnlTransport` 显示出来又会把视频区挤矮，
每次显示 / 收起 libvlc 都要重排输出、画面跳一下。

结论：进度条做成**独立、置顶、不激活**的小窗口（`Owner=主窗口`、`WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`），
视频区尺寸永远不变。

## 5. 如实说明

- **DVD 只放主标题**：用 `dvdsimple://` 而不是 `dvd://`。后者会停在 DVD 菜单上，而本程序没有菜单导航
  （方向键 / 回车选菜单）——**能显示却点不动的菜单是死路**，所以这一轮不做菜单。
- **蓝光只识别、不支持**：插件在包里，但加密蓝光缺 AACS 密钥库，本机也没有蓝光设备，
  没有真机验证过的代码不写进发行版；菜单里这一项是灰的并写明"暂不支持"。
- **CSS 加密的 DVD 会失败**：不随包分发 `libdvdcss.dll`（法律原因）；用户自己放一个到
  `libvlc\win-x64\` 下可用。这张测试盘没有加密，实测能放。
- **音频 CD 没有实物可验**：只验到"识别 + `cdda:///L:` + 走同一条播放路径"，
  真机上没有 CD 可插，这一点写进 README 的已知限制。
- **任务栏按钮**：系统界面上到底画没画出来，冒烟验不到；本次用真机悬停截图确认了那排四个按钮，
  但不同 Windows 版本的预览面板样式会不一样。
- **全屏进度条是独立窗口**：它浮在画面上、不在画面里；Alt+Tab 走开会立刻收起。
  它不抢焦点，但**盖住的那一条画面收不到右键菜单**（`CursorOverVideo` 只认画面窗口）。
- 125% / 150% 缩放与多屏切换，冒烟仍覆盖不到，需要真机看一眼。

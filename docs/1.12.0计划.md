# 1.12.0 更新计划

> 所有者 2026-11-05 点名六件事：
> ① 加**音频迷你模式**；
> ② 把 **NowPlayingView 与窗口模式管理**进一步独立；
> ③ **播放引擎与播放业务分离**；
> ④ **音频窗口 / 视频窗口 / 全屏**各自成为独立界面模块；
> ⑤ **播放列表 / 媒体会话 / 历史记录**各自拥有明确的数据所有权；
> ⑥ 不同功能的**菜单、快捷键、任务栏**共用同一套命令。
>
> 版本号 **1.12.0**（迷你模式是用户看得见的新能力 → 次版本）。
> 状态：**已实现、全量验证通过，待发布**。

## 5. 如实说明

- **迷你模式固定置顶**（仅迷你期间；退出恢复 `Settings.AlwaysOnTop`）。「窗口置顶」菜单项在迷你里置灰。
- **迷你模式里视频只出声、不显示画面**（用户自己选的形态；切歌不会被自动形态推翻）。
- **迷你窗口的标准标题栏保留**（拖动、任务栏按钮、全局媒体键、任务栏缩略图按钮照常）。
- **迷你卡片右键不弹画面菜单**（画面菜单只在视频画面上；卡片有自己的「还原」与双击）。
- `PlaybackCoordinator` 仍是"界面线程上的业务层"，没有做异步 / 消息队列；
  这是与 1.11.0 相同的线程约定（所有引擎回调都弹回 UI 线程）。
- 冒烟仍验不到"迷你窗在真实桌面上的观感"、125% / 150% 缩放的像素级细节与多屏几何；
  这些要真机看一眼（和以前一样如实写）。
- 已知偶发红：进度条拖动那一条（维护手册 R2 / M1）在机器很忙时仍可能红一次，复跑即绿，判据未动。

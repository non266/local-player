# 1.16.0 计划：光盘菜单、标题与章节（把「能显示却点不动」变成能走通）

> 版本：1.16.0（2026-11-09 立项）。范围 = 所有者选定的「DVD 菜单 / 章节 / 多标题」
> （外部评审第 6 条，也是 1.11.0 明写的边界）。
> 本文是**计划稿**：第 2 节的真盘实测**已经做完**，第 3 节之后要动的产品代码**一行还没动**。
> 老规矩：断言 + 变异 + 文档；**不设计时断言**（R2 的教训）。

## 1. 起因与取舍

1.11.0 把 DVD 做成 `dvdsimple://` 直接放主标题，理由写在 `Core/OpticalDisc.BuildMrl`
的注释里：`dvd://` 会停在 DVD 菜单上，而本程序没有菜单导航——"能显示却点不动的菜单是死路"。
外部评审第 6 条建议用 `libvlc_media_player_navigate` 把这条路补上。

本轮先花半天做了一次**只量不判**的真盘探针（§2，真盘 `L:`，一次性控制台程序，不入库）。
结论比预想的干脆：菜单不光能显示，`Navigate` 能移动高亮、能进子菜单，`Title` / `Chapter`
也能切——**全都不依赖窗口焦点**，纯 API 就能走通。于是本轮范围定成：

| 事项 | 本轮 |
| --- | --- |
| 默认打开 DVD 走菜单（`dvd://`） | **做**（本轮**唯一**的用户可见行为变化） |
| 方向键 / 回车 / Esc → `Navigate` | **做**；只在菜单显示时接管，平时仍是快退 / 快进 / 音量 |
| 「播放 → 标题」子菜单（列当前盘的标题，勾当前） | **做** |
| 章节 | 「播放 → 章节」**本来就有**（`MainForm.Chapters.cs`），DVD 上直接可用：本轮只给它补上「第 2 章 / 共 5 章」的文字与真盘断言，不重写 |
| 画面右键菜单里的光盘入口（全屏时唯一入口） | **做**：上 / 下 / 左 / 右 / 确定 / 回到菜单 |
| 菜单打不开时自动退回主标题 | **做**，只退一次，**就地改当前条目**（不新增第二行） |
| 鼠标点菜单 | **试了一次**：这张盘上没验成（EnableMouseInput 是只写属性，没有可判据的反馈），已如实写进 README 与 D5 |
| 蓝光 / CSS 加密盘 / 音频 CD | 不动（蓝光仍只识别、不支持） |

## 2. 先量（真盘探针，2026-11-09 19:48–19:52）

探针是 `%TEMP%\dvdprobe` 里的一次性控制台程序：`Core.Initialize` 指向 `bin\Release\…\libvlc\win-x64`，
`new Media(libvlc, "dvd:///L:", FromType.FromLocation)`，`--no-audio`，用 `TakeSnapshot` 留证据。

| 动作 | 实际结果 |
| --- | --- |
| `Play("dvd:///L:")` | **6.2 秒**进入 `Playing`，停在菜单 |
| 菜单上的读数 | `TitleCount = 13`、`Title = 0`、`ChapterCount = 7`、`ChapterCountForTitle(1) = 5`、`Length = 466 ms` |
| `Navigate(2)`（下）×2 | 快照 SHA 从 `ED9C5101…` 变成 `F2578ED8…`（104,560 → 136,769 字节）；肉眼看高亮从「play all」移到「select」 |
| `Navigate(0)`（确定） | 进到这张盘自己的**章节选择子菜单**（6 张缩略图 + 翻页箭头，快照 267,790 字节）——子菜单进得去 |
| `Title = 2` | `Time = 1,842 ms`、`Length = 1,419,233 ms`（约 23:39）、`Chapter` 归 0 |
| `Chapter = 1` | `Time = 58,099 ms`（章节号是 **0 基**） |
| `dvdsimple:///L:` | 3.4 秒开播，`Title = 0`、`Length = 1,429,434 ms`（**23:49.4**，与 1.15.0 验收的 `00:23:49` 对上了）、`TitleCount = 12` |
| `dvdsimple` 下 `Title = 1 / 2 / 3` | 长度 1,419,234 / 1,419,434 / 1,419,234 ms，章数 6 / 5 / 7（各集长度只差 1 秒，**不能靠长度认集数**） |
| 假盘符 `dvd:///Z:`、`dvdsimple:///Z:` | `EncounteredError` **立刻**到（< 1 秒）；但 `State` 不会停在 `Error`——25 秒时仍是 `Ended` |

三条直接影响设计的结论：

1. **菜单模式靠"当前条目是 `dvd://`，且 `Title == 0 && TitleCount > 1`"就能认出来**，不用猜、不用看画面；
2. **失败回退必须挂错误事件，不能轮询 `State == Error`**（后者根本等不到）；
3. **两种 MRL 的标题编号差 1**：`dvd://` 的 title 0 是菜单（466 ms）、内容标题是 1..12（`TitleCount = 13`）；
   `dvdsimple://` 的 title 0 就是主标题（23:49.4，`TitleCount = 12`）。所以「标题」菜单只对
   `dvd://` 建（1..`TitleCount - 1`），状态栏也按 `Title / (TitleCount - 1)` 显示；「直接播放主标题」
   走 `dvdsimple://`，它的 `Title` 报 0——**不要把两边的编号混着用**。

## 3. 实现

### 3.1 `Core/DvdMenu.cs`（新文件，纯逻辑，不碰 libvlc）

```csharp
public static class DvdMenu
{
    // libvlc_navigate_mode：activate=0, up=1, down=2, left=3, right=4, popup=5
    public const uint Activate = 0, Up = 1, Down = 2, Left = 3, Right = 4, Popup = 5;

    public static uint? NavigateFor(Keys key);          // ↑↓←→ / Enter，其余 null（Esc 不接：全屏时它是退出全屏）
    public static bool IsMenu(string? mrl, int title, int titleCount);   // 必须是 dvd://，且 titleCount > 1 && title <= 0
    public static string DescribeTitle(int index, int chapterCount);
    public static bool ShouldFallBack(string? mrl, bool alreadyTried, bool error);
}
```

- `ShouldFallBack`：只有 `dvd://`、没试过、且**错误事件到了**才回退。原计划写"或 8 秒还没 Playing"，
  实现时按实测砍掉了：坏盘的错误 1 秒内就到，超时那一条永远等不到（`State` 停在 `Ended`）。
- 纯逻辑的用意：这四条都能在**不插盘**的冒烟里验，每次真盘回归只验"菜单真的动了"。

### 3.2 `Core/OpticalDisc.cs`

- `BuildMrl(DvdVideo)` → `dvd:///L:`（菜单），注释改成"菜单由 `DvdMenu` 负责导航"。
- 新增 `BuildSimpleMrl(kind, root)` → `dvdsimple:///L:`，供「直接播放主标题」与失败回退用。
- `DescribeLocation` 已经认 `dvd` / `dvdsimple`，不用改。

### 3.3 主窗体接线

- `MainForm.Disc.cs`：
  - `_discFallbackLetter`（哪个盘已经退过主标题）、`_discStatusText`（状态栏位置只在变化时刷）、
    `_discFallbackNotice`（留一份回退说明给断言读——状态栏那句会被紧接着的"已停止"盖掉）；
  - `TryNavigateDiscMenu(Keys key)`：`DvdMenu.IsOnScreen(...)` 为真才 `Player.Navigate(...)`；
  - `PlayMainTitleOfCurrentDisc()` / `ReturnToDiscMenu()` / `SwitchDiscTitle()` / `SwitchDiscMrl()`；
  - `TryFallBackDiscMenu()`：在 `PlayerEngine.ErrorOccurred` 的处理器最前面判 `DvdMenu.ShouldFallBack` →
    `_playlist.SetPath(当前项, BuildSimpleMrl(...))` → 重新 `PlayIndex`，状态栏说明；**同一条错误不再往下走**
    （不标红、不自动跳过）。
- `Core/Playlist.cs` 新增 `SetPath(int index, string path)`：`PlaylistItem.FilePath` 是只读的，
  所以是**换一个新条目对象、保留 `AddedOrder`**，触发一次 `Changed`；`PlaylistWorkspace` 透传一个同名方法。
  断言里必须验"还是同一条、`AddedOrder` 没变、列表没有多出一行"。
- `MainForm.Shortcuts.cs`：在 `PlayerCommandCatalog.TryMap` **之前**插一道
  `if (TryNavigateDiscMenu(keyData)) return true;`——只在菜单确实在屏上时抢键，
  平时的方向键（快退 / 快进 / 音量）一个都不动；`Esc` 不接（全屏时它是退出全屏）。
- `MainForm.DiscMenu.cs`（新分部，照「章节」的做法）：
  - 「播放 → 标题」子菜单，`DropDownOpening` 时按 `TitleCount` 重建，标 `1..TitleCount-1`（0 是菜单），
    当前项打勾；DVD 之外保持隐藏；
  - 「章节」已有，DVD 上把文字补成「章节（第 2 章 / 共 5 章）」；
  - 「回到菜单」：当前是 `dvd://` 就 `Title = 0`（`Navigate(Popup)` 也能回菜单根）；
    **当前是 `dvdsimple://` 时先 `SetPath` 换回 `dvd://` 再重开**——主标题的 title 0 是正片，不是菜单；
  - 「直接播放主标题」：`SetPath` + `PlayIndex`。
- `MainForm.VideoMenu.cs`：画面右键菜单加「光盘菜单」子菜单（上 / 下 / 左 / 右 / 确定 / 回到菜单）
  与「直接播放主标题」——全屏时菜单栏收起来了，这是唯一入口。
- `MainForm.UiTimer.cs` / `UpdateTransportState`：菜单模式下进度条与时间标签显示 `--:--`、不接受拖动
  （菜单 title 只有 466 ms，显示成 `0:00` 会让人以为坏了）；播放标题时状态栏带 `标题 3 / 12 · 第 2 章`。
- `MainForm.Shell.cs` 的 `ExtraShortcutsText`：加一句"光盘菜单：方向键移动，回车确认，Esc 回菜单根"。

## 4. 测试与变异

### 4.1 断言（不插盘也能跑的那一半）

新增第 **27** 项「光盘菜单」（放进第 17 步「光盘」，`StepCount` 26 → 27）：

1. `NavigateFor`：↑↓←→ / Enter → 1 / 2 / 3 / 4 / 0；`A` 与 `Space` → `null`；`Esc` → `null`
   （全屏时它是退出全屏，不能被菜单吃掉）；
2. `IsMenu`：`("dvd:///L:", 0, 13)` → `true`；`("dvd:///L:", 2, 13)` → `false`；
   `("dvd:///L:", 0, 1)` → `false`（普通视频）；`("dvdsimple:///L:", 0, 12)` → `false`（主标题不是菜单）；
   `(@"C:\music\a.mp3", 0, 3)` → `false`；
3. 位置文案：菜单上是「菜单」、正片是「标题 2 / 12 · 第 1 章」、`dvdsimple` 返回空串；
4. `BuildMrl(DvdVideo) == "dvd:///L:"`、`BuildSimpleMrl(...) == "dvdsimple:///L:"`、`BuildMrl(AudioCd)` 仍是 `cdda:///L:`；
   `LetterOfMrl("dvd:///L:") == "L:"`、普通路径认不出盘符；
5. `ShouldFallBack`：`dvd://` + 没试过 + 出错 → `true`；已试过 → `false`；`dvdsimple://` → `false`；没出错 → `false`；
6. `SetPath`：换完之后列表**仍是 3 条**、第 1 / 第 3 条不动、`IndexOfPath` 找得到新路径、旧路径消失、
   `AddedOrder` 没变、`Changed` / `ContentChanged` 各一次（同路径再设一次不重复通知）。

新增第 **27** 项的后半段「假盘符回退」（同样不插盘）：`dvd:///Z:` 打不开 → 自动换成
`dvdsimple:///Z:`、`HasFallenBackFromDiscMenu("Z:")` 为真、列表仍只有 1 条、说明留在
`DiscFallbackNotice` 里（状态栏那句会被紧接着的"已停止"盖掉，所以单独记一份）、等 2 秒确认没有第二次。

**改旧断言**（不是放宽）：第 21 项原来断言 `BuildMrl(DvdVideo) == "dvdsimple:///L:"`，
那是 1.11.0 的产品决定；本轮按新口径拆成两条（`dvd://` 是菜单、`dvdsimple://` 是主标题），
原断言留在同一项里，改写成两条各自的用例；m3u 往返也同时验两种 MRL。

### 4.2 真盘（`播放器_TEST_DISC=L:`，没盘就打印原因跳过）

真盘那一段**并进第 21 项**（那里本来就打开了这张盘，另起一个窗体要再等一次光盘转起来）：

1. 点「打开光盘」→ 等到 `Playing`，`IsDiscMenuOnScreen` 为真（`Title == 0`、`TitleCount = 13`）；
2. 进度条被置灰（`SeekBarEnabled == false`）；画面右键菜单里有可用的「光盘菜单 → 菜单：上」；
3. **按一下回车**（`ProcessShortcut(Keys.Enter)`，真走 `ProcessCmdKey` → 菜单导航）→
   `Title == 1`、`Length > 1,000,000 ms`（默认高亮是「play all」）；进度条恢复可拖；
4. 「播放 → 光盘 → 标题 2」→ `Title == 2`、`Length` 仍是正片量级；`SetChapter(1)` → `Time > 10 秒`；
5. 「回到菜单」→ `IsDiscMenuOnScreen` 又为真；「直接播放主标题」→ 路径变 `dvdsimple:///L:`、
   列表**仍只有一条**、`Length` 读得出来。

### 4.3 变异（逐条按预期以具体的话变红）

| 变异 | 实际失败的话 |
| --- | --- |
| `NavigateFor` 把 Enter 映射成 `Down` | `光盘菜单：回车 没有映射成「Activate」（映射成了 Down）` |
| `IsMenuOnScreen` 恒 `false` | `光盘菜单：「这是不是菜单」判错了（dvd:// 的 title 0 才是菜单…）` |
| 去掉回退的"只退一次" | `光盘菜单：同一个盘会退两次（第二次还是 dvd:// 的状态）` |
| `SetPath` 里顺手 `Add` 一条 | `光盘菜单：换地址把别的条目挤掉了（现在 4 条）` |
| `BuildMrl` 仍返回 `dvdsimple://` | `光盘：DVD 打开时没有走菜单（MRL 是「dvdsimple:///L:」，期望 dvd:///L:）` |
| 拿掉 `ProcessCmdKey` 里的 `TryNavigateDiscMenu` 接线 | `光盘真盘检查：菜单在屏上时按回车没有被窗口接住（回车掉到别处去了）` |

> **第一版的第 6 条变异是绿的**：当时用"按「下」前后各截一张图、SHA 不同"当证据，而菜单背景
> 本身在动，两张截图天然不同——接线拿掉了照样"通过"。改成"按回车必须进正片"（`Title` 与
> `Length` 都变）之后才变红。这条写进了维护手册坑表，也写进 ARCHITECTURE §22.3。
## 5. 不做 / 已知边界

- **鼠标点菜单没有验**：`EnableMouseInput` 是只写属性；真盘上点得动点不动没试过。
  方向键与画面右键菜单是真盘验过的（按回车真的进了正片），鼠标点击这一条如实写进已知限制（D5）。
- **上一首 / 下一首仍是播放列表项**，不是 DVD 的标题；标题之间切换走「播放 → 标题」或菜单本身。
- **菜单里的字幕 / 音轨**由 DVD 自己的菜单管；此时本程序的字幕 / 音轨菜单作用于菜单画面，没有意义，文档写明。
- **菜单模式下的进度条**显示 `--:--:--` 并置灰（466 ms 的菜单 title 没有"进度"可言）；
  真盘验过"菜单上拖不动、进正片恢复"。
- **蓝光仍只识别、不支持**；CSS 加密 DVD 仍失败（不随包分发 `libdvdcss`）。
- **菜单 title 的 `Length`（466 ms）**写进文档：它是菜单这个"title"的时长，不是影片时长。
- **没有菜单的盘**：`dvd://` 下如果 `Title` 一直是 0，本程序会把方向键让给 `Navigate`（空操作），
  快退 / 快进来不及生效。开工时尽量找一张无菜单的盘验一次；验不到就如实写进已知限制，
  并说明**「直接播放主标题」换到 `dvdsimple://` 之后方向键立刻恢复**（那时 `IsMenu` 为假）。
- **标题编号只在 `dvd://` 下用**：切到 `dvdsimple://` 之后原来那个"标题 2"不再是同一集（差 1），
  所以「标题」菜单在 `dvdsimple` 下不显示（只留「回到菜单」与「直接播放主标题」的反向操作）。

## 6. 验收与回滚

- 全量冒烟 **27 项 / 22 个运行步骤**，实测 **197.7 秒**（1.15.0 是 26 项 / 172.7 秒；
  多出来的是第 27 项的假盘符回退与真盘那一段的几个等待）；`docs-check` 的口径句四处同步。
- 真盘回归就是第 21 项那一段（一次跑完）：菜单出现 → 进度条置灰 → 右键菜单有入口 →
  回车进正片 → 标题 2 → 第 2 章 → 回到菜单 → 直接播放主标题 → 列表仍只有一条；实测 **11 秒**跑完。
- 回退用假盘符 `Z:` 验（第 27 项，不需要真盘）：错误事件立刻到 → 自动换 `dvdsimple://` → 只退一次。
- 干净树 `release-check` 与 `dist\` 三版、规模数字对账（例行 R18）在发版那一轮做。
- **收尾如实说明**：`release-check` 前两次都撞在**已知的第 11 项收尾原生崩**（`0xCFFFFFFF`，
  维护手册坑表里 1.12.0 那条，同一处、同一收尾顺序）；直接跑全量两次全绿（197.7 / 173.7 秒），
  第三次 `release-check` 全绿（**179 秒**）。为确认不是本轮改动引入，另开 1.15.0 的 worktree 做对照：
  `主窗体` 那一步两边各跑 7 次，1.16.0 崩 2 次、1.15.0 一次没崩——样本小、不能下"没变差"的结论，
  也不能下"变差了"的结论；**判据没放宽、产品代码没改**，如实记在这里与 CHANGELOG。
- 回滚：`BuildMrl` 一行改回 `dvdsimple://`、`TryNavigateDiscMenu` 直接 `return false`，
  其余新增代码不影响无盘路径；回滚后冒烟应仍 27 项全绿（第 27 项只验纯逻辑）。

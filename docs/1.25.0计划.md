# 1.25.0 计划：文件页搜索 / 类型筛选 / 拖到播放列表 / 定位当前文件

> 状态：**实现中（2026-11-18）**，未发版。范围 = 所有者 2026-11-18「制定新版本的计划」后批准的
> 四项；版本 1.25.0（用户看得见的新能力，按次版本）；本轮只做实现与验证，等所有者说「发布」。

## 1. 范围

| 做 | 不做 | 理由 |
| --- | --- | --- |
| 当前文件夹搜索（文件名、多关键字与关系、`Ctrl+F` / `Esc`） | 递归搜索 / 建索引 | 递归要另一套有界 I/O、结果上限与取消；搜索框先做"眼前这一层"的即时过滤 |
| 只看类型（视频 / 音频 / 字幕 / 播放列表；文件夹始终在） | 缩略图（图片 / 视频首帧 / 音频封面） | ListView 大图标在 5,000～20,000 项下要做可见行懒加载、图片缓存、网络盘超时；单独一轮 |
| 拖到播放列表（文件 + 文件夹，内部有界） | 文件夹树 / 删除 / 改名 / 移动 / SMB 自动发现 / 自动刷新 | 1.24.0 的边界不变 |
| 定位当前播放文件（侧栏 / 悬浮侧栏 / 分离窗口） | 从播放列表反向定位、批量定位 | 只做"当前正在播的那一个" |
| 第 33 项内新增断言 + 8 条变异 | 新增第 34 项检查、改冒烟口径 | 四项都属于文件页，放进现有检查更集中 |
| 不新增设置字段（仍 7 组 92 项） | 持久化搜索词 / 类型筛选 | 两者都是临时视图态；导航到别的目录就清掉 |

## 2. 设计

### 2.1 搜索与类型筛选

- `Core/FileBrowserFilter`：纯逻辑，不碰磁盘。
  - `Matches(entry, query)`：按空白切词、每个词都要命中 `entry.Name`（`OrdinalIgnoreCase`）；
    空查询全过。只匹配文件名，不把完整路径算进去（否则输入当前文件夹名会命中全部）。
  - `MatchesType(entry, filter)`：文件夹 / 磁盘**永远通过**；文件按 `FileBrowserKind` 比对。
- `Ui/FileBrowserView`：工具栏下方加一行搜索框（Dock Top，`Scaled(30)`）；
  `TextChanged` 只重排 `_visibleEntries`，不读磁盘。
- `Ui/FileBrowserView.Behavior`：`FillList` 先过滤再建行；状态行有筛选时写
  「只看视频 · 筛选 3/12 项（1 个文件夹）」；`Ctrl+F` / `Esc` / `Enter` 接线；
  目录导航清空搜索与类型，F5 刷新保留。
- 类型筛选放在「位置 → 只看类型」菜单，不用 ComboBox：避免下拉框获得焦点后
  空格键的去向问题，也省侧栏宽度。

### 2.2 拖到播放列表

- `Core/FileBrowserDrag.Format = "播放器.FileBrowserPaths"`。
- 文件页的 `ItemDrag` 构造 `DataObject`，同时放 `DataFormats.FileDrop`（外部程序）与内部格式。
- `MainForm.Files.HandleDrop` 先看内部格式：有就走
  `AddPathsWithFolders(..., boundedLocalFolders: true)`；没有才按外部 `FileDrop` 的旧行为。
  文件夹递归仍是 32 层 / 200,000 文件、不跟重解析点。拖放不删除 / 不移动 / 不改名。

### 2.3 定位当前播放文件

- 文件页「位置」菜单顶部「定位当前播放文件」→ `LocateRequested`。
- `MainForm.FileBrowser.LocateCurrentFileInBrowser`：只认本地文件；网络流 / 光盘 / 文件已不在
  分别给状态栏说明；音频 / 迷你窗口且文件页不可达时只说明，不强行切窗口形态。
- `FileBrowserView.NavigateToFile`：清空临时筛选、导航到所在目录、记 `_pendingSelectPath`，
  目录读完后按 `FullPath` 选中并 `EnsureVisible`；分离窗口 / 悬浮侧栏由 `ShowFileBrowser`
  的既有入口负责亮出来。

## 4. 测试

### 4.1 第 33 项新增断言（`StepCount` 仍 33）

- 搜索：`play` → 只剩 `play.wav`；`PLAY` 大小写不敏感；`play srt` → 0 项；清空恢复全部；
  状态行含「筛选」。
- 类型：只看视频 → `movie.mkv` + `nested`，`play.wav` 不在；只看音频 → `play.wav` + `nested`，
  `movie.mkv` 不在；切回全部恢复。
- 键盘：列表上 `Ctrl+F` 焦点进搜索框；搜索框里 `Space` / `Delete` 不被命令层吃掉。
- 拖放：选中 3 项 → `FileDrop` 与内部格式都含 3 条路径；40 层目录深处的文件拖放后不进播放列表。
- 定位：播放 `play.wav` → 导航到 `nested` → 定位 → 回到 `uiRoot` 并选中 `play.wav`；
  分离窗口里直接 `NavigateToFile` 也能选中。
- 搜索行停靠在列表上方（防止 Dock 顺序写反）。

### 4.2 变异（8 条，实测原文）

| # | 变异 | 实测红 |
| --- | --- | --- |
| 1 | `Matches` 不匹配时也返回 true | `文件页检查：搜索「play」之后列表没有变少（nested / list.m3u / movie.mkv / play.wav / sub.srt）` |
| 2 | 多关键字改成"或"关系 | `文件页检查：搜索两个关键字时匹配了只含一个关键字的项（play.wav / sub.srt）` |
| 3 | 搜索改成大小写敏感 | `文件页检查：搜索大小写不同的文件名没有匹配` |

## 8. 边界

- 搜索只筛当前一层、只匹配文件名；不是资源管理器的递归搜索，也不建索引。
- 类型筛选只筛文件；文件夹与磁盘始终可见；筛选是临时视图态，不落盘。
- 拖放文件夹有界（32 层 / 200,000 文件）；拖到外部程序仍是普通 `FileDrop`。
- 定位只认本地文件；网络流 / 光盘 / 文件已不在只给状态栏说明。
- 缩略图、文件夹树、删除 / 改名 / 移动、SMB 自动发现、自动刷新不做；缩略图另立一轮。
- 已知 Application Hang（`0xCFFFFFFF`）本轮未修；验收仍按"关掉其它播放器、每次留间隔"处理。

> 状态：**已实现（未发版）**。基线 `HEAD = a024b15`（1.31.0 发行记录）；
> `<Version>` 1.31.0 → **1.32.0**；本轮不打包、不打标签、不发 GitHub Release。
> 范围 = 把 1.31.0 打开的多选真正收口（整批移动 + 误删撤销）+ 一处缩略图文档旧口径。

## 1. 为什么是这两件事

- 1.31.0 把 `listViewPlaylist.MultiSelect` 打开了，但 `MoveSelected` 仍要求
  `selected.Count == 1`，`OnPlaylistItemDrag` 也明确拒绝多选。用户能选中三行，却只能删 /
  排队 / 复制，整批整理仍然做不到。
- 同一版让 `Ctrl+A` + `Delete` 可以一次删掉整个列表，而移除没有确认、没有撤销。这是新入口
  带来的真实误删风险，应该在下一轮补上安全网。
- `docs/介绍.md` 的功能总览还写着缩略图"只在内存缓存"，与 1.28.0 的 128 MB 落盘缓存、同文
  「已知限制」互相矛盾。

## 3. 行为规格

### 3.1 整批移动（块语义）

- 选中索引统一由 `GetSelectedPlaylistIndices()` 升序取出；块内相对顺序不变。
- 上移 / 下移把整个块移到"最近的未选中前一项之前 / 后一项之后"：
  `[a,b,c,d,e,f]` 选 `[b,d]`，上移 → `[b,d,a,c,e,f]`；下移 → `[a,c,e,b,d,f]`。
- 拖动换位：落点在选中块范围（含首尾边界）内不移动；拖到块之前 / 之后才重排。
  例：`[a,b,c,d,e,f]` 选 `[b,d]` 拖到末尾 → `[a,c,e,f,b,d]`。
- 边界：第一项不能再上移、最后一项不能再下移；菜单置灰，工具栏点击在状态栏说明。
- 筛选 + 多选：整批移动 / 拖动禁用，提示「筛选状态下不能整批移动，请先清空搜索框」；
  单选移动保持 1.31.0 行为。
- 移动后重新选中块；当前项按对象引用重算；排序依据退回「原始顺序」。

### 3.2 撤销最近一次移除

- 移除前保存"条目对象 + 原索引 + 移除后的条数"。
- `Ctrl+Z`（焦点在播放列表，固定键，与 `Delete` / `Enter` 同类）或右键
  「撤销移除 N 项(&Z)」：条目回原索引、重新选中、状态栏「已撤销移除：恢复 N 项（不恢复播放）」。
- 只有一级；任何内容变化（添加 / 排序 / 载入 / 移动 / 清空）都失效；播放 / 暂停 / 切歌
  （`Changed` 但条数、内容不变）不失效。
- 不落盘；`Clear` 仍走确认框，不纳入撤销。

## 5. 测试

### 5.1 第 35 步 / 第 40 项

6 条 10 秒合成 WAV，两个 `MainForm` 实例：

1. 选中 [1,3]：菜单「上移 2 项」可点；上移 → `[p1,p3,p0,p2,p4,p5]`，选中 [0,1]。
2. 下移 → `[p0,p1,p3,p2,p4,p5]`，选中 [1,2]。
3. 选 [0,1] 用测试钩子拖到末尾 → `[p3,p2,p4,p5,p0,p1]`，选中 [4,5]。
4. 第一项上移置灰；最后一项下移置灰。
5. 筛选状态下选两项：上移 / 下移置灰，调用移动给原因且顺序不变。
6. 第二个窗体：移除 2 项 → 4 项；「撤销移除 2 项」可点；`Ctrl+Z` 恢复 6 项、原顺序、选中 [1,3]。
7. 排序（`ContentChanged`）后快照失效；再加一个文件（条数变）后也失效；无快照时 `Ctrl+Z`
   不改列表并说明。
8. 纯模型：`MoveMany` 当前项在块内 / 块外都保持同一对象；`InsertRestored` 保持当前项。

### 5.2 变异（逐条临时改、确认红、复原）

## 7. 边界与如实说明

- 撤销只有一级，不恢复播放，不落盘；清空列表仍有确认框、不提供撤销。
- 非连续选中按"块"移动会跨过中间未选中的项，这是本轮定义的语义，不是逐项换位。
- 筛选状态下不能整批移动 / 拖动；单选移动仍可用。
- 50,000 条的移动 / 撤销各仍整建一次界面（约 1.5 秒），本轮没有重新量。
- 真实 `DoDragDrop` 的多选路径无法在冒烟里合成鼠标；覆盖的是 `CanReorderPlaylist` +
  `ReorderSelectedTo`，没有人工鼠标 / 200% DPI 验收。
- 本轮不发版：没有 tag / 打包 / GitHub Release；安装体积标签仍是 1.31.0 的实测值。

## 8. 明确不做

- 不做多级撤销 / 重做、不做撤销落盘、不恢复被删项的播放。
- 不做"移动到指定行号"输入框。
- 不在筛选状态下做整批移动 / 拖动。
- 不优化 50,000 条的整建耗时；不做真人鼠标拖动验收。
- 不处理 DVD 鼠标菜单、关窗挂起根因、20k 平铺虚拟化。

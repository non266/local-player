# 1.7.0 更新计划

> 这一版是 **1.6.2 之后第一次"加东西"**：按规矩要先有所有者点名（1.5.0 计划第 1 节的那条），
> 这份文档就是点名记录与施工图。
> **已点名并做完**：`A3`（去隔行「自动」是空选项，修掉）+ `F3`（按文件记住音轨 / 字幕轨）
> + `F4`（播放列表「找出重复项」）。**F5～F9 没点名，一行代码都没动**，规格留在这里，
> 下次点名可以直接照做。

## 0. 这一版装了什么（都已完成，见 CHANGELOG 的 `[1.7.0]` 节）

| # | 一句话 | 成本 | 结果 |
| --- | --- | --- | --- |
| **A3** | 去隔行菜单里的「自动」实测等于「关闭」（libvlc 3 不认 `auto`），删掉 | 0.5 天 | 模式表 9 → 8 项；老设置 / 老方案 / 导入 json 里的 `auto` 归一成"关闭"；菜单与设置各一条断言、两条变异 |
| **F3** | 选过的音轨 / 字幕轨按文件记住（含「关闭字幕」），下次打开自动选回去 | 1～1.5 天 | `history.json` 只增两个可空字段；第 13 步用 ffmpeg 现造的 2 音轨 + 2 字幕轨样本验"关掉重开确实是那两个 id"；「关闭字幕」单独验；两条变异 |
| **F4** | 播放列表右键「找出重复项」：保留第一次出现的那一项，其余只选中、不自动删 | 0.5 天 | 纯函数 `Core/PlaylistDuplicates.cs` + 运行时插进右键菜单（不改 Designer）；第 2 步新增检查；一条变异 |

**为什么是这三条**：A3 是 A 类静默失败（"按了没反应"），按维护纪律随时可以插队修；
F3 是真实的长尾别扭（双语 MKV / 带评论音轨的片子每次都要重选），且能落到"引擎当前轨道 id"
这种硬判据上；F4 便宜、低风险、判据能落在纯函数上。三条都不改既有语义，凑成一个次版本。

**这一版没做的**：`F5`～`F9`（见第 1 节）、C 类 12 条、MainForm 族拆分（17.5 的不拆判据）。

## 1. 候选清单（**等所有者点名**）

点名规则照 1.3.0 / 1.5.0 的先例：**点一条做一条，没点名的一条都不动代码**。
每条按"行为 / 改动点 / 断言 / 变异 / 风险与如实说明 / 成本"写全。

| 候选 | 一句话 | 成本 | 风险 | 推荐 |
| --- | --- | --- | --- | --- |
| **F5**（M2 / B4）筛选状态下拖动换位 | 现在直接拒绝并提示 | 半天 | 低（要先定死插入语义） | ★★☆ |
| **F6** 进度条悬停出画面缩略图 | 第二条解码链 + 缓存 | 2～3 天 | 高（性能 + 新解码路径） | ⭐ 先不做 |
| **F7** 字幕外观（字号 / 位置 / 背景） | 要换内核，且可能根本改不了 | 探针 10 分钟 + ≥1 天 | **高（很可能像 C1 一样不生效）** | ⭐ 先探针 |
| **F8** 网络串流的最近地址 | 打开串流对话框里列最近 10 条 | 半天 | 低 | ⭐ 没需求就别做 |
| **F9** 真正的「自动」去隔行 | 内核级 `--deinterlace=-1`，按片源自动判断 | ≥1 天 | 中高（要动内核缓存键，牵 M8 那套） | ★★☆ |

### F5（M2 / B4）筛选状态下拖动换位（半天）

- **现状**：`MainForm.Search.cs` 的 `OnPlaylistItemDrag` 在筛选时直接拒绝并提示（有意为之）。
- **要动就先定死语义**：把选中项插到目标**可见行**在模型里的位置（跨过被筛掉的行）。
- **断言**：第 2 步加一段——6 项筛出 3 项，把第 3 个可见项拖到第 1 个可见项之前，
  清空筛选后断言模型顺序、且只动了 1 项；**变异**：按可见下标而非模型下标插入 → 红。
- **说明**：这是维护手册 B 表的 B4；不做判据仍是"没人被绊住就不动"。

### F6 进度条悬停出画面缩略图（2～3 天，**这一轮不做**）

- **现状**：悬停已经有时间气泡（`Ui\FlatSlider.cs` 的 `HoverTipFormatter`），缺的是"那一帧的画面"。
- **为什么不排**：第二条解码链 + 每文件的缩略图缓存 + 快速划过时的取消，还要保证大文件 /
  几万条列表下不掉帧；风险与 M8 同级，单独立项。

### F7 字幕外观（字号 / 位置 / 背景）（**先探针**）

- **现状**：libvlc 3 里与字幕外观有关的选项（`--freetype-*`、`--sub-margin` 等）都是**内核级**，
  运行时改就得换内核（照 B-2 那套）；3.0 没有 `libvlc_video_set_subtitle_*` 这类运行时 API。
- **所以先花 10 分钟探针**：`--freetype-rel-fontsize=N` 换内核之后字幕**真的变大了吗**？
  变了再谈 UI（还要接"按文件记住"或全局设置）；**不变就照 C1 的先例记成 C 类"不改"**。

### F8 网络串流的最近地址（半天，**没需求就别做**）

- **现状**：网络串流不记录（地址没有稳定标识），也没有"上次连过的地址"。
- **行为**：`文件 → 打开网络串流…` 下面列最近 10 条地址（同一地址去重、最后用的排最前），可清空。
- **说明**：价值完全取决于所有者用不用串流。

### F9 真正的「自动」去隔行（≥1 天）

- **为什么有它**：1.7.0 删掉的「自动」其实是 libvlc 3 播放器级接口不认 `auto`（A3）。
  真正"按片源自动判断"要用内核级 `--deinterlace=-1`（配合 `--deinterlace-mode=auto`）。
- **代价**：内核现在是**按旋转值缓存**的（`PlayerEngine.CoreSlot`，1.5.0 为 M8 做的）；
  再按"自动去隔行"开一档缓存键，等于把"内核参数 → 缓存键"从 1 维变 2 维，
  还要在切换时重铺状态、验证不泄漏原生线程（M8 的教训）。
- **风险**：换内核那条路已经踩过 `0xC0000005`；没有"连续切换 N 次线程不涨 + 全量连跑"的判据之前不许上。
- **断言（先想好）**：`CoreArguments` 带 `--deinterlace=-1` 的纯逻辑；
  隔行素材上"自动"与"关闭"必须不同（正好用 R8 的探针）；换档 300 次线程数不涨。
- **成本**：≥1 天，且建议单独立一轮（不要和别的功能混）。

## 3. 假设

- 本机：Win10 19045、SDK **10.0.402**（`global.json` 钉住）、Inno Setup 6、7-Zip、`gh` 已登录；
  ffmpeg 8.0 在 `D:\ffmpeg-8.0-full_build\bin\ffmpeg.exe`（多轨 / 隔行 / 四象限素材都从它造）。
- 真视频素材仍由 `播放器_TEST_VIDEO` 指定；没设就跳过第 13 步里依赖它的那一段（既有约定不变）。
- **数据只增不改**：F3 给 `history.json` 的按文件记录加了 `AudioTrackId` / `SubtitleTrackId`
  （可空，空值不写进 JSON；老文件读出来是 null）。A3 把设置里的 `auto` 归成"关闭"（行为不变）。
- 冒烟仍是 20 步：新检查挂在第 2 步（F4）/ 第 4 步（A3 的纯逻辑）/ 第 13 步（F3）。

## 4. 每条都要交的东西（house rules）

1. **断言**：判据要能区分"环境不成立"与"功能坏了"，跳过必须打印原因；
   别拿"早先拍下的状态"当基准；等待型判据要问"**是不是它**"。
2. **变异**：把被测行为改坏，必须**以一句具体的话**变红。
3. `tools\release-check.ps1` 全绿（Debug / Release 0 警告 0 错误 + 全量 20 步）。
4. 文档同批：README（功能面）、[docs/介绍.md](介绍.md)、[CHANGELOG.md](../CHANGELOG.md)、
   本手册的分诊表 / 更新节奏。
5. **新文件不要顶破 500 行**：1.7.0 的 F3 / F4 测试就各自放了自己的文件
   （`Program.Video.Tracks.cs` / `Program.MainForm.Duplicates.cs`）。

## 5. 明确不做（这次翻不了案）

- **画面调整（亮度 / 对比度 / 饱和度 / 色相 / 伽马）**：C1 实试在 3.0.24 上会把画面弄成纯绿。
- **逐字染色（卡拉 OK）**：LRC / SYLT 里没有逐字时间轴（C8）。
- **歌词编辑与内建在线歌词搜索**：在线获取走 LrcAPI 已够用（C4）。
- **DLNA / NAS 媒体库、皮肤、跨平台**：复杂度过收益（C3）。
- **按文件记住去隔行模式**：去隔行现在是全局设置；按文件记会牵动"换内核 / 重开媒体"的语义，
  没有点名不做（记在这里，免得下次重新想）。
